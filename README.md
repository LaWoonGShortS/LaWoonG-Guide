## 📚 주요 파일 목록

### 1. **index.html** - 메인 페이지
**접속 경로**: `/` 또는 `/index.html`

**주요 기능**:

- 🔗 YouTube 채널 링크

### 2. **guide-presentation.html** - 가이드 프레젠테이션 ✨ NEW!
**접속 경로**: `/guide-presentation.html`

드래곤소드 공략 사이트의 모든 기능을 9개 슬라이드로 설명하는 인터랙티브 프레젠테이션입니다.

**주요 기능**:
- 📊 **9개 슬라이드**: 타이틀 → 메인 소개 → 6개 가이드 → 마무리
- ⌨️ **키보드 조작**: 
  - `→` 또는 `Space`: 다음 슬라이드
  - `←`: 이전 슬라이드
- 🖱️ **마우스 조작**: 
  - 하단 `이전`/`다음` 버튼
  - 진행도 점 클릭으로 특정 슬라이드 점프
- 🔄 **순환 네비게이션**: 9번 슬라이드에서 다음 → 1번으로 자동 이동
- 🎨 **Glassmorphism 디자인**: 보라색 그라데이션 배경
- 📱 **반응형**: 데스크탑, 태블릿, 모바일 최적화

**슬라이드 구성**:
1. 타이틀 페이지 - DragonSword 로고, 6개 배지
2. 메인 페이지 소개 - 6개 가이드, 핵심 기능
3. 결정 위치 공략 - 4종 결정, 10개 지도
4. 오르비스 주화 - 50개, 매주 리셋
5. 퍼즐 위치 - 40개, 5개 지역
6. 새알 위치 ⭐ - 84개, 인터랙티브 지도
7. 요리 레시피 - 구글 스프레드시트
8. 다람쥐 런 - 3개 지역, 4시간 리젠
9. 마무리 - 요약 및 YouTube 링크

**추천 사용법**:
- 전체 화면 모드 (F11) 권장
- YouTube 영상 녹화용으로 최적화
- 공식 소개 자료로 활용 가능

### 3. **dragonsword-결정.html** - 결정 위치 공략 💎
**접속 경로**: `/dragonsword-결정.html`

드래곤소드의 4가지 결정(추억/회상/기억/망각) 위치를 상세하게 안내합니다.

**주요 내용**:
- ❤️ **추억의 결정** (빨간색) - 여신상 주변
- 🧡 **회상의 결정** (주황색) - 특징 없음
- 💙 **기억의 결정** (하늘색) - 얕은 물가
- 💜 **망각의 결정** (보라색) - 동굴 내부

**기능**:
- 📷 10개의 상세 지도 이미지
- ⚠️ 골렘 몬스터 경고 정보
- 📱 반응형 디자인
- 🌓 다크모드/라이트모드

### 4. **dragonsword-오르비스주화.html** - 오르비스 주화 수집 💰
**접속 경로**: `/dragonsword-오르비스주화.html`

매주 월요일 리셋되는 오르비스 주화 50개의 수집 루트와 진행도를 관리하는 체크리스트입니다.

**주요 기능**:
- 🔢 **50개 수집 포인트** - 숫자 그리드 레이아웃
- ✅ **체크리스트 시스템** - 클릭으로 수집 여부 표시
- 📊 **실시간 진행도 트래커** (0/50, 퍼센티지)
- 💾 **자동 저장** - LocalStorage 활용
- 🗺️ **인터랙티브 지도** - 확대/축소 가능
- 🌓 **다크모드/라이트모드** 토글

**통계 기능**:
- 전체 수집 개수
- 오늘 수집 개수
- 남은 개수
- 달성률 (%)

### 5. **dragonsword-퍼즐.html** - 퍼즐 위치 수집 🧩
**접속 경로**: `/dragonsword-퍼즐.html`

5개 지역에 흩어진 40개 퍼즐 위치를 지역별로 색상 구분하여 표시합니다.

**주요 기능**:
- 🌈 **5개 지역 색상 구분**:
  - 💜 칼파루옥 (5개) - 보라색
  - 🧡 단풍 지대 (8개) - 주황색
  - 💙 무너진 경대 (8개) - 파란색
  - 💚 푸른라스 벌판 (10개) - 초록색
  - 💖 리아닌 (9개) - 핑크색
- 🎯 **지역별 필터링** - 원하는 지역만 볼 수 있음
- ✅ **40개 체크리스트** - 클릭으로 수집 표시
- 📊 **진행도 트래커** (0/40)
- 💾 **자동 저장** - LocalStorage
- 🗺️ **인터랙티브 지도**

### 6. **dragonsword-새알.html** - 새알 위치 수집 🥚 ⭐ 핵심 가이드!
**접속 경로**: `/dragonsword-새알.html`

84개의 새알 위치를 **인터랙티브 지도 마커 시스템**으로 표시하고, 실시간 진행도를 추적합니다.

**핵심 기능**:
- 🗺️ **인터랙티브 지도**: 84개 정확한 마커 위치
- 🖱️ **마커 클릭 시스템**: 마커 클릭 → 진행도 자동 증가
- 📊 **실시간 진행도**: 수집 개수, 남은 개수, 달성률 (%)
- 🔍 **지도 확대/축소**: 50% ~ 300% (기본 100%)
- 🖐️ **Alt+드래그 이동**: Alt 키 누른 채 드래그로 지도 이동
- 📍 **마커 크기 최적화**: 14px (작고 명확)
- ⚠️ **마커 겹침 경고**: 너무 가까운 마커는 노란색으로 표시
- 📋 **좌표 목록**: 모든 마커의 x%, y% 좌표 표시
- 📤 **좌표 배열 복사**: 새로운 새알 위치 추가 시 클립보드에 복사

**조작 방법**:
- **마커 추가**: 지도 클릭 (Alt 키 없이)
- **마커 삭제**: 마커 클릭
- **지도 이동**: `Alt` + 드래그
- **확대/축소**: `Ctrl` + 마우스 휠 또는 우측 상단 버튼

**새로운 새알 위치 추가 방법**:
1. 지도를 확대/축소하고 Alt+드래그로 이동
2. 새알 위치를 클릭해 마커 추가
3. 84개 완성 후 '좌표 배열 복사' 버튼 클릭
4. 복사된 코드를 전달하면 페이지 업데이트
