# 🐉 드래곤소드 공략 가이드

드래곤소드 게임의 필수 수집 아이템 공략 모음입니다.

## 📚 공략 목록

### 1. 결정 위치 공략 (메인 페이지)
**파일**: `index.html`  
**접속 경로**: `/` 또는 `/index.html`

드래곤소드의 4가지 결정(추억/회상/기억/망각) 위치를 상세하게 안내합니다.

**주요 내용**:
- ❤️ **추억의 결정** (빨간색) - 여신상 주변
- 🧡 **회상의 결정** (주황색) - 특징 없음
- 💙 **기억의 결정** (하늘색) - 얕은 물가
- 💜 **망각의 결정** (보라색) - 동굴 내부

**기능**:
- 10개의 상세 지도 이미지
- 골렘 몬스터 경고 정보
- 반응형 디자인

---

### 2. 오르비스 주화 수집 가이드 ⭐ NEW
**파일**: `dragonsword-ovis-coin.html`  
**접속 경로**: `/dragonsword-ovis-coin.html`

매주 리셋되는 오르비스 주화 50개의 수집 루트와 진행도를 관리하는 인터랙티브 체크리스트입니다.

**주요 기능**:
- 🔢 **50개 수집 포인트** - 숫자 그리드 레이아웃
- ✅ **체크리스트 시스템** - 클릭으로 수집 여부 표시
- 📊 **실시간 진행도 트래커** (0/50, 퍼센티지)
- 💾 **자동 저장** - LocalStorage 활용
- 🗺️ **인터랙티브 지도** - 확대/축소 가능
- 🌓 **다크모드/라이트모드** 토글
- 📱 **모바일 최적화**

**통계 기능**:
- 전체 수집 개수
- 오늘 수집 개수
- 남은 개수
- 달성률 (%)

---

## 🔗 페이지 간 연결

- 메인 페이지(결정 공략) → 오르비스 주화 가이드로 이동 가능
- 오르비스 주화 가이드 → 메인 페이지로 돌아가기 가능

## 🛠️ 기술 스택

- **HTML5** - 시맨틱 마크업
- **CSS3** - Glassmorphism 디자인
- **JavaScript (Vanilla)** - 순수 JS
- **Tailwind CSS** - 유틸리티 CSS 프레임워크
- **Font Awesome** - 아이콘
- **LocalStorage API** - 클라이언트 데이터 저장

## 💾 데이터 저장 방식

### 오르비스 주화 가이드
```javascript
// LocalStorage에 저장
localStorage.setItem('genshin-orobashi-collected', '[1, 3, 5, ...]')

// 저장되는 정보
- 수집한 포인트 ID 배열
- 마지막 방문 날짜
- 오늘 수집 카운트
```

**특징**:
- ✅ 브라우저에 영구 저장
- ✅ 인터넷 없이 작동
- ✅ 빠른 응답 속도
- ⚠️ 같은 브라우저에서만 유지
