# 🐉 드래곤소드 공략 가이드

드래곤소드 게임의 필수 수집 아이템 공략 6종 세트입니다.

## 📚 공략 목록

### 1. 결정 위치 공략 💎
**파일**: `dragonsword-결정.html`  
**접속 경로**: `/dragonsword-결정.html`

드래곤소드의 4가지 결정(추억/회상/기억/망각) 위치를 상세하게 안내합니다.

**주요 내용**:
- ❤️ **추억의 결정** (빨간색) - 여신상 주변
- 🧡 **회상의 결정** (주황색) - 특징 없음
- 💙 **기억의 결정** (하늘색) - 얕은 물가
- 💜 **망각의 결정** (보라색) - 동굴 내부

**기능**:
- 📷 10개의 상세 지도 이미지
- ⚠️ 골렘 몬스터 경고 정보
- 📱 반응형 디자인

**제작 정보**:
- 📝 작성자: 참깨마왕
- ✏️ 편집자: 비밀리 (LaWoonG ShortS)

### 2. 오르비스 주화 수집 가이드 💰
**파일**: `dragonsword-오르비스주화.html`  
**접속 경로**: `/dragonsword-오르비스주화.html`

매주 월요일 리셋되는 오르비스 주화 50개의 수집 루트와 진행도를 관리하는 체크리스트입니다.

**주요 기능**:
- 🔢 **50개 수집 포인트** - 숫자 그리드 레이아웃
- ✅ **체크리스트 시스템** - 클릭으로 수집 여부 표시
- 📊 **실시간 진행도 트래커** (0/50, 퍼센티지)
- 💾 **자동 저장** - LocalStorage 활용
- 🗺️ **인터랙티브 지도** - 확대/축소 가능
- 🌓 **다크모드/라이트모드** 토글

**통계 기능**:
- 전체 수집 개수
- 오늘 수집 개수
- 남은 개수
- 달성률 (%)

**제작 정보**:
- 📝 작성자: 일루전(드소갤)
- ✏️ 편집자: 비밀리 (LaWoonG ShortS)

### 3. 퍼즐 위치 40개 수집 가이드 🧩
**파일**: `dragonsword-퍼즐.html`  
**접속 경로**: `/dragonsword-퍼즐.html`

5개 지역에 숨겨진 퍼즐 40개의 위치를 안내하고 진행도를 관리합니다.

**5개 지역 (색상별)**:
- 🟣 **보라색** (5개) - 칼파루옥
- 🟠 **주황색** (8개) - 단풍 지대
- 🔴 **빨강색** (8개) - 무너진 경대
- 🔵 **파랑색** (10개) - 푸른라스 벌판
- 🟡 **노랑색** (9개) - 리아닌 위치

**주요 기능**:
- 🗺️ **지역별 필터링** - 카드 클릭으로 지역별 퍼즐만 표시
- 🔢 **40개 체크리스트** - 숫자 그리드 레이아웃
- 📊 **지역별 진행도** - 각 지역의 수집 현황 실시간 표시
- 💾 **자동 저장** - LocalStorage 활용
- 🎨 **지역별 색상 코드** - 보라/주황/빨강/파랑/노랑
- 🌓 **다크모드/라이트모드** 토글

**통계 기능**:
- 전체 수집 개수 (0/40)
- 지역별 수집 현황
- 오늘 수집 개수
- 달성률 (%)

**제작 정보**:
- 📝 작성자: 엉망진창겜유이
- ✏️ 편집자: 비밀리 (LaWoonG ShortS)

- 📊 **실시간 진행도 트래커** (0/90, 퍼센티지)

**통계 기능**:
